# 钉钉工作台能力（v1.8.0）

本文说明 AIHub 助理如何以成员**本人的钉钉身份**处理审批、待办与日程，管理员的配置步骤，以及后续可接入的钉钉能力清单。

## 权限模型

钉钉 OpenAPI 使用企业应用凭证调用，钉钉本身不会按「当前用户」鉴权，因此由 AIHub 服务端强制执行以下规则：

- **身份只认钉钉验证过的来源**：通过钉钉登录（含经统一认证下发的钉钉 userId）得到的身份，或成员在钉钉中与机器人对话时自动建立的绑定。管理员在后台手动绑定、或仅凭邮箱推断的账号只能接收通知，不能用于审批、待办、日程操作，避免通过改绑越权。多个来源不一致时一律拒绝。
- **操作人由服务端注入**：模型无法传入或更改操作人。成员须在钉钉通讯录中处于在职状态。
- **逐项校验**：同意 / 拒绝 / 转交 / 退回 / 加签仅限本人为当前处理人的任务；撤销仅限本人发起的审批；模板管理须具备钉钉 OA 审批管理权限；日程修改与删除仅限组织者。
- **写操作二次确认**：所有写操作在对话中弹出确认卡片，展示服务端解析后的完整摘要（以谁的身份、对哪张单据、具体内容）。该确认不受「自动批准工具」设置影响；无界面的运行环境下直接拦截。信息不明确时助理会先追问。
- **审计**：所有写操作、自动审批执行与企业查询调用均写入审计日志。

## 管理员配置

以下能力统一使用「通用设置 → IM 连接器 → 钉钉」中的服务号（通知应用）凭证。

1. 钉钉开发者后台 → 服务号对应的企业内部应用 → 权限管理，按需开通：

| 能力               | 权限点                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| 审批               | `Workflow.Instance.Read`、`Workflow.Instance.Write`、`Workflow.Form.Read`、`Workflow.Form.Write`、`qyapi_get_member`    |
| 审批（退回、加签、待我处理列表） | `Premium.Workflow.ReadWrite.All`（需企业已购买 OA 审批高级版）                                                                   |
| 待办               | `Todo.Todo.Read`、`Todo.Todo.Write`                                                                                  |
| 日程               | `Calendar.Event.Read`、`Calendar.Event.Write`、`Calendar.EventSchedule.Read`、`VideoConference.Conference.Read`（会议室列表） |

2. AIHub 管理端 → 通用设置 → IM 连接器 → 钉钉 →「工作台能力」：开启审批 / 待办 / 日程，选择自动审批档位，点击「检查权限」确认权限点齐全。

## 审批

| 钉钉 App 中的操作                   | 助理是否支持     | 说明                                           |
| ----------------------------- | ---------- | -------------------------------------------- |
| 发起审批                          | 支持         | 钉钉套件模板（请假、人事等）不支持通过接口发起                      |
| 查看待我处理 / 我发起的 / 详情            | 支持         | 未购买高级版时，待我处理列表通过扫描近 30 天进行中的单据得到，单据量很大时可能不完整 |
| 同意 / 拒绝 / 转交 / 评论 / 撤销        | 支持         | 撤销须模板允许提交人撤销，且发起 15 秒后方可操作                   |
| 退回 / 加签                       | 需 OA 审批高级版 |                                              |
| 创建 / 修改 / 删除审批模板              | 支持         | 接口只能维护表单字段；审批流程节点与可见范围须在钉钉管理后台设置             |
| 催办、撤回已作出的审批、审批后追加抄送、重新提交、删除单据 | 不支持        | 钉钉未开放接口                                      |
| 上传附件                          | 不支持        | 钉钉要求通过客户端上传                                  |

### 自动审批规则

成员可在对话中用自然语言创建规则（例如「自动同意我团队 1 天以内的请假」）。助理将其编译为结构化条件（指定模板 + 发起人 / 部门 + 表单字段比较），确认卡片展示编译结果。规则执行时只做确定性匹配，不调用模型。

- 动作：同意、拒绝、转交（固定对象）、评论，均可附固定意见。
- 后台每 2 分钟检查一次，仅处理规则所有者本人为当前处理人的任务（含本人发起后流转回本人的单据）。
- 每次执行写入审计并通过钉钉工作通知告知本人；钉钉身份失效时规则自动停用。
- 成员在「设置 → 自动审批规则」查看、停用、删除规则及执行记录；管理员可在后台查看全员规则并强制停用。

档位由管理员在钉钉连接器卡片中切换，默认「适中」：

| 档位 | 有效期                     | 每条规则每日上限 |
| -- | ----------------------- | -------- |
| 关闭 | 不允许创建或执行规则（已有规则保留，暂停执行） | —        |
| 严格 | 必填，默认 30 天，最长 90 天      | 20 单     |
| 适中 | 可选，可长期有效                | 50 单     |
| 宽松 | 可选，可长期有效                | 不限       |

收紧到「严格」时，现有规则的有效期会缩短至 90 天内，并通知规则所有者。

## 待办与日程

- **待办**：创建、修改、完成、删除本人待办，可指派给同事（需确认）。受钉钉接口限制，只能查询和维护通过 AIHub 创建的待办；此类待办在钉钉中点击后跳转 AIHub，由助理标记完成。
- **日程**：查询、创建、修改、删除本人主日历日程，邀请参会人（需确认），预订会议室，响应邀请。查询同事忙闲时只返回忙 / 闲时段，不含日程内容。

## 后续可接入能力清单

以下能力尚未接入，供评估。标注「本人」的能力必须绑定成员本人的钉钉身份，规则同上。

| 能力            | 可实现的自然语言场景         | 权限绑定             | 风险与限制                        |
| ------------- | ------------------ | ---------------- | ---------------------------- |
| 考勤与假期         | 查询本人打卡记录、迟到早退、假期余额 | 本人，只读            | 低。补卡 / 请假本质是审批单，套件模板无法通过接口发起 |
| 日志（日报 / 周报）   | 按模板撰写并提交日志；汇总下属日志  | 本人；读取他人日志须为日志接收人 | 中。提交后不可通过接口撤回                |
| 通讯录查询         | 查同事部门、职位、汇报关系      | 登录成员即可，只读        | 低。已有组织架构镜像，手机号等敏感字段应屏蔽       |
| 钉钉文档 / 知识库    | 搜索、阅读、创建文档，总结知识库内容 | 本人，按文档权限         | 中。须逐文档校验本人权限，接口覆盖不完整         |
| 钉盘            | 查找、下载文件供助理分析       | 本人，按空间权限         | 中。同上                         |
| 会议            | 创建视频会议、查询会议纪要与录制   | 本人（组织者 / 参会人）    | 中。纪要含敏感内容                    |
| 公告            | 起草并发布企业公告          | 须具备钉钉公告管理权限      | 高。面向全员，须二次确认并限制管理员           |
| DING / 工作通知   | 向指定同事发送提醒          | 本人发起，服务号发送       | 中。已由「提醒」能力覆盖大部分场景            |
| 群消息           | 向群发送消息、创建群         | 本人须为群成员          | 高。易造成打扰，接口仅支持机器人所在群          |
| 智能人事          | 查询花名册、入转调离         | 须具备人事管理权限        | 高。含个人敏感信息，建议暂不接入             |
| 智能填表 / 宜搭     | 查询、提交表单数据          | 本人，按表单权限         | 中。取决于企业是否使用                  |
| Teambition 项目 | 查询、创建、更新项目任务       | 本人，按项目成员权限       | 低至中。取决于企业是否使用                |
| 客户管理（CRM）     | 查询、跟进客户记录          | 本人，按数据权限         | 中。取决于企业是否使用                  |
