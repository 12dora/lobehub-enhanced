# 企业查询（v1.8.0）

助理可通过自然语言查询企业工商、风险、知识产权、招投标等信息，数据来自企查查与天眼查。凭证由管理员统一配置，成员不可见。

## 管理员配置

管理端 → 通用设置 → 基础设施 →「企业查询」卡片：

| 配置项         | 说明                                                             |
| ----------- | -------------------------------------------------------------- |
| 企查查 API Key | 在 [企查查智能体数据平台](https://agent.qcc.com) 登录后，头像菜单 →「获取我的 API KEY」 |
| 企查查查询类目     | 默认开启企业、风险、知识产权、经营、高管、法规、案例、招投标；「历史沿革」须先在企查查完成企业实名认证，「文档解析」默认关闭 |
| 天眼查 API Key | 在 [天眼查 AI 平台](https://www.tianyancha.com/ai) 获取                |
| 默认供应商       | 两家都启用时优先使用的供应商；成员点名某一家时按成员指定                                   |
| 失败时自动切换     | 默认供应商凭证无效、额度用尽或无法连接时，10 分钟内改用另一家                               |
| 每人每日上限      | 默认 50 次，0 表示不限。仅成功的查询计数                                        |

凭证以 `PLATFORM_MASTER_KEY` 加密写入 `platform_infra_settings`（id = `enterprise_lookup`），接口只返回是否已保存及指纹。保存属于敏感操作，需重新验证身份并写入审计。

## 运行方式

- 服务端以管理员凭证代理调用两家的 MCP 服务（企查查 `https://agent.qcc.com/mcp/<类目>/stream`，天眼查 `https://mcp.tianyancha.com/v1`），请求经统一出站通道，遵循网络代理设置。
- 未配置任何供应商时，「企业查询」工具不会提供给助理。管理员也可在管理端的工具治理中对其设置停用或需审批。
- 企业名称存在多个匹配时，助理会列出候选并请成员确认，不会自行猜测；回答中会注明数据来源。
- 每次查询写入审计日志（操作人、供应商、能力、查询关键词），不记录凭证与完整返回内容。

## 计费提示

两家均按调用计费（企查查 1 积分约 0.1 元，单个企业每月有积分上限）。建议保留每人每日上限，并只开启需要的查询类目。
